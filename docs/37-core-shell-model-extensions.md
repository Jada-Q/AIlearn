# 核壳模型的举一反三：五个扩展，和一条不许省的边界

> 2026-08-16 · 续 [33](./33-agent-harness-anatomy.md)、[34](./34-harness-floor-model-ceiling.md)：从 DeepSeek Harness 源码提炼的"概率核+确定壳"模型，往 AI 学习、生活与业务三个方向的迁移

拆完 DeepSeek Harness 之后，我手里剩下一个可携带的抽象：**任何系统 = 一个聪明但不可靠的概率核 + 一层不聪明但绝对可靠的确定壳**。壳的零件永远是四样——账本（不许撒谎）、门禁（默认拒绝）、循环（错误喂回去）、压缩（旧事变摘要）。

这个模型能迁移到哪？迁移之前，先立边界。

## 边界：什么时候这个模型不适用

核壳模型只适用于一种系统：**有"聪明但不可靠的决策核"、且它的错误会真实改变世界。**两类系统不适用：

- **没有核的纯机械流程**——不需要壳，它本身就是壳；
- **纯创作活动**——过度套壳会杀死核。给艺术装太多门禁，上限会被壳锁死。创作要的是低门禁、高账本（多记录、少拦截）。

"万物皆可套"是好类比最大的死法。带着边界用，它才是工具而不是锤子。

## 五个扩展（按杠杆距离排序）

### 1. AI 学习：四零件阅读透镜

看任何新 AI 产品、agent 框架、论文，直接问四个问题：**账本在哪（状态怎么记）？门禁在哪（什么默认拒绝）？循环在哪（错误怎么喂回去）？压缩在哪（记忆怎么有损）？**答不全的产品，缺的那个零件就是它未来翻车的位置。这比读十篇测评快。

### 2. 生活：失败之后，修壳，不骂核

**自责是在骂模型，改进是在修 harness。**"我怎么又没坚持"是在怪核不够聪明——但核的不可靠是前提，不是过错。正确的问题永远是：这件事的壳缺了哪个零件？没账本（做没做全凭感觉）？没门禁（诱惑默认放行）？没循环（失败即中断，没有喂回去重试）？公司治理早就这么干（错误日志、同类错误两次升级成硬规则），生活里同一套。

### 3. 学习理论：好奇心定上限，复习系统定下限

复习库是账本，间隔复习是在**对抗大脑的 compaction**——睡眠会有损压缩记忆，复习就是把重要条目反复调回前台，防止被摘要掉。Feynman 检查是 verify 门，错题回炉是循环。推论：没有复习壳的学习，学得再嗨都会被睡眠压缩掉细节；但只有复习壳、没有好奇心驱动的学习，下限稳了上限死了。两个零件管两端。

### 4. 业务：交付机制，不交付建议

咨询行业的通病是交付"核的输出"（建议、判断）——客户点头，回去照旧。核壳模型给出差异化：**建议会被遗忘（压缩是必然的），机制才会留下。**审计类交付的正确形态不是"你该改这些"，而是一套客户自己能重复跑的检查清单+复查节奏。对执行力平庸的客户团队尤其值钱——弱模型+强壳提升最大（麦当劳定律，见 [34](./34-harness-floor-model-ceiling.md)）。

### 5. 内容：可系列化，但先过数据门

"核壳"世界观可以系列化成内容 IP（每期拆一个领域的 harness：记账的、飞行的、健身的）。但系列 = 预支产能承诺，违反 dogfood 纪律。正确顺序：先看已发内容的真实数据（阅读/转发），有信号再谈系列。没信号，它就是几篇好文章——这已经够了。

## 总认识：先查壳，再怪核

这个模型真正的价值是一个**归因顺序**：任何系统出问题（AI 的、公司的、身体的、学习的），先查壳的四个零件，最后才怀疑核。它会改变力气的分配方式——

**聪明是稀缺的、贵的、难改的；壳是便宜的、当天就能焊的。**

大多数人的一生都在试图升级核，而文明的秘密从来是：核没怎么变过，壳越焊越好。
