# 两张地图指向同一处：Jeff Dean × Andrew Ng，价值正在向"定义"和"判定"两端迁移

> 2026-08-16 · 源：Jeff Dean 告别访谈（YC，2026-07）× Andrew Ng《The AI Engineering Skills Map》（X，2026-08-15）· 前篇：[35 — Jeff Dean 建议权重表](./35-jeff-dean-advice-for-vibe-coders.md)

一周之内读到两份东西：Jeff Dean 作为 Googler 的最后一次公开访谈，和 Andrew Ng 基于一万多条招聘数据画的 AI 工程技能地图。两人数据源完全不同——一个是造了三十年基础设施的建造者视角，一个是劳动力市场的聚类视角——结论却严丝合缝。独立信源交汇的地方，通常就是真东西所在。

## Ng 的四项技能，一句话版

1. **构建部署 AI 应用**：AI 软件的本质区别是输出不可预测，核心技能是用统计手段治理不确定性——有纪律的 evals + 错误分析循环。
2. **软件工程基本功**：懂原理才看得见 agent 替你做的取舍；基本功的用途是"用软件工程的精确语言指挥 agent"，不是自己手写代码。
3. **用好 coding agent**：正确心智模型、上下文管理、给 agent 配验证器让它自主闭环、spec 的写与不写、多 agent 编排。
4. **塑造要造什么（Shaping the build）**：spec 给足则交付渐强，工程师的重心移向"决定 spec 里写什么"——产品感、业务上下文、客户目标。

注脚：Ng 经营 DeepLearning.AI，此文兼有市场定调功能。数据方法是实的，但读时应知道画地图的人也在地图上开店。

## 两人的交汇点

| 交汇点 | Dean（建造者视角） | Ng（市场视角） |
|---|---|---|
| 评估 | 自动化的前提是好评估器 | 核心技能是 evals + 错误分析循环 |
| 规格 | agent 不会追问，清晰度决定产出 | 工作重心移向"spec 里该写什么" |
| 选题 | 品味是唯一稀缺技能 | Shaping the build 需要产品感与业务上下文 |

合成一句话：**价值正在从"执行"的中段，向上下两端迁移——上游是"定义"（造什么、spec 写什么），下游是"判定"（造出来的对不对、好不好）。中段（把 spec 变成代码）正在被商品化。**

## 他们凭什么这么判断：三条底层逻辑

**瓶颈会迁移。**系统围绕最稀缺的资源重组：算力稀缺时硬件工程师值钱，写码稀缺时程序员值钱。代码生成趋于无限供给后，稀缺性迁到供给不了的地方——"想要什么"的真值只存在于人和真实世界（上游定义值钱），"对不对"的判定不随生成变便宜（下游评估值钱）。Dean 和 Ng 不是预言家，他们只是都在盯同一个问题：下一个瓶颈在哪。

**互补品升值。**一样东西降价，它的互补品升值——打印机便宜了，墨盒赚钱。执行免费了，执行的互补品全线升值：spec、评测、领域知识、信任、分发。很多人手里的专业资格、行业经验、审美，都是"执行"的互补品，过去两年相对价格一直在涨，只是没有行情表让人看见。

**范式从逻辑转向统计。**传统软件确定性强，测一次就够；AI 软件输出不可预测，"治理不确定性"从一次性动作变成常设职能。这解释了 evals 为什么从边缘技能升为核心技能——它是新范式下的质检科。

## 按"势 / 位 / 行"读成行动地图

判断只有翻译成"我站在哪、该往哪走"才有用。以我自己为例（一人 + AI 公司，FP2 × 建筑出身 × 在日跨境，agent 基建过配、选题判断刚被押注实验测出 2/5 的校准率）：

**势**：水退石出。执行之水退去，露出两块石头——上游的定义、下游的判定。此势有三个独立信源互证：建造者（Dean）、市场（Ng），以及我一个月前写进预测账本的同方向判断（"执行正确性被基建解决后，瓶颈迁移到目标正确性"）——预测账本第一次收到利息：还不足以判命中，但方向性证据 +1。

**位**：多数开发者强在基本功（技能 2）、弱在业务感（技能 4）；我恰好倒挂——技能 3 超配、技能 4 有原料没校准、技能 2 最弱。倒挂在此势下是好事：势的方向奖励 4、贬值 2 的相对价格。风险只有一个：优势位的判断力还没校准，原料好但秤不准。

**行**（按先后）：
1. **守校准循环**：项目开工前写 30 天预测，到期对账。练的是技能 4 的核心肌肉，势里最贵的那块。
2. **把 evals 建在"自己是 ground truth"的领域**：税务答案正误评测集、设计品味评分表。私人判断力一旦写成评测集，就从技能变成资产——独有数据，Dean 说的壁垒形态之一。
3. **基本功只补"指挥用词汇"**：每个项目讲透一层原理，攒取舍意识，够指挥 agent 就停，不贪学位。
4. **停止给已超配的层加建**：agent 工具链是富余产能，90 天不加新基建，把真实工作灌进去。

一句话卦辞：**势在两端，居上端者有粮无秤——先造秤（evals + 对账），再售粮（把评估器做成产品）；中段勿恋战，下端可外包。**

## 给读者的通用版

把上面的个人参数抽掉，通用行动指导是三问：

1. 你现在的技能组合里，哪些属于"中段"（正在被商品化的执行）？——别再往里投入。
2. 你有没有一个"只有你能当 ground truth"的领域？——那是你该建 evals 的地方，也是你未来的资产。
3. 你上一次写下可对账的预测是什么时候？——没有对账记录的判断力，涨不了。
